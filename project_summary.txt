1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This workspace implements and compares two parameter-efficient approaches for
genomic sequence modeling on the Human Non-TATA Promoters dataset
("katarinagresova/Genomic_Benchmarks_human_nontata_promoters"):

  A) Classical Fine-Tuned DNABERT-2 (finetune_dnabert.py)
  B) Hybrid Quantum-Classical Genomic Adaptation / Quantum-LoRA (quantum_lora_genomics.py)

Both approaches freeze the heavy 117M-parameter DNABERT-2 transformer backbone
and train only lightweight downstream layers/adapters, making them fast and
effective in low-data regimes on CPU.

3. MODEL B: HYBRID QUANTUM-CLASSICAL ADAPTATION (QUANTUM-LORA)
--------------------------------------------------------------------------------
- Script:          quantum_lora_genomics.py
- Base Backbone:   quietflamingo/dnabert2-no-flashattention (BertModel, frozen)
- Saved Artifact:  ./quantum_lora_adapters.pt
                     keys: ['classifier_state_dict', 'regressor_state_dict']
- Dataset Split:   200 Train / 50 Val / 100 Test
                   (Train: 112 Promoter, 88 Non-Promoter;
                    Val:    22 Promoter, 28 Non-Promoter;
                    Test:   45 Promoter, 55 Non-Promoter;
                    Missing=0, InvalidDNA=0)
- Architecture:
    1) Frozen Backbone: DNABERT-2 extracts 768-D pooled sequence embeddings
       (117,068,544 frozen parameters).
    2) Quantum Bottleneck: nn.Linear(768, 4) compresses 768-D features into 4
       dimensions, followed by torch.tanh(...) * (pi / 2) to map features into
       quantum rotation angles in [-pi/2, pi/2].
    3) Quantum Variational Circuit: 4-Qubit PennyLane default.qubit circuit
       using AngleEmbedding + 2 layers of StronglyEntanglingLayers, measuring
       PauliZ expectation values on all 4 qubits.
    4) Task Heads:
       - QuantumDNAClassifier: Linear(4, 2) for Binary Classification
       - QuantumDNARegressor:  Linear(4, 1) for Quantitative Expression Strength
- Parameter Count:
    * Total Parameters:             117,071,654
    * Trainable (Classifier):             3,110 (0.00266% of total)
    * Trainable (Regressor):              3,105
- Observed Results:
    * Task 1 - Low-Data Binary Classification (25 epochs, AdamW lr=0.015):
        - Train Accuracy:   0.860 (86.0%)
        - Test Accuracy:    0.750 (75.0%)
        - Test F1-Score:    0.719
        - Test ROC-AUC:     0.824
    * Task 2 - Quantitative Regression (80 epochs, AdamW lr=0.03):
        - Test MSE:         1.1953
        - Test R2:          0.2567
        - Pearson r:        0.5890


4. COMPARISON & KEY TAKEAWAYS
--------------------------------------------------------------------------------
- Extreme Parameter Efficiency:
  Quantum-LoRA trains ~190x fewer parameters (3,110 vs. 592,130) while
  achieving comparable test accuracy (75.0% vs. 76.56%) and strong ranking
  performance (ROC-AUC 0.824) on low-data genomic splits.
- Multi-Task Capability:
  DNABERT-2 Trainer focuses on discrete binary promoter classification, while
  Quantum-LoRA demonstrates both binary classification and continuous
  expression-strength regression (Pearson r = 0.5890) from the same frozen
  768-D genomic representations.
